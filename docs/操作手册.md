# Web Basic Admin · 操作手册

> 面向使用者：怎么登录、每个菜单能做什么、遇到问题怎么处理。
> 二次开发请看 [开发手册](./开发手册.md)。

---

## 1. 登录与账号

### 1.1 登录

1. 打开系统地址，输入账号与密码。
2. 按系统配置，可能需要填图形验证码、拖动滑块（两者都能被管理员在「站点设置」里关闭）。
3. 忘记密码请联系管理员重置；连续输错会触发锁定（默认 5 次锁定 10 分钟）。

### 1.2 密码规则（设置/修改密码时必须满足）

- 至少 **8 位**；
- 必须同时包含**大写字母、小写字母、数字**；
- 不能是常见弱口令（如 `12345678`、`password`、`admin123`）；
- 不能出现 3 个及以上连续相同的字符（如 `aaa`、`111`）。

页面会直接提示还缺什么，不用反复试。修改成功后当前账号所有登录状态失效，需要用新密码重新登录。

### 1.3 锁屏与退出

- 右上角头像 → **锁定屏幕**：临时离开时锁屏，输入密码解锁（不退出登录）。
- 右上角头像 → **退出登录**：清空会话，回到登录页（服务端会同步吊销当前会话）。

### 1.4 个人中心

右上角头像 → 个人中心：

- **头像**：鼠标移到头像上或点「上传头像」选图，上传后点「保存」生效，右上角头像同步更新。
- **资料**：昵称、性别、邮箱、手机号，保存后立即生效。
- **修改密码**：见 §1.2。

### 1.5 使用文档

右上角头像 → **使用文档**：弹出内置说明窗口（快速开始、工作台、密码规则、常见问题），不需要另开页面。

## 2. 工作台

首页即工作台：

- **顶部 4 张卡片**：用户总数、角色/部门、文件总量、今日登录（含在线会话与今日操作数）。
- **下方页签**：三个页签在同一个卡片里切换，不用跳页面：

| 页签 | 能做什么 |
| --- | --- |
| 我的待办 | 新建（标题 / 优先级 / 截止时间 / 业务链接）、完成、恢复、删除；逾期标红；「查看业务」跳回业务单据 |
| 我的消息 | 查看站内信、标记已读、全部已读、删除；点标题看详情 |
| 通知公告 | 管理员发布的公告，点标题看详情并自动标记已读 |

- **顶栏铃铛**：显示通知 / 消息 / 待办三类未读数，点条目或「查看全部」直接跳到工作台对应页签。

## 3. 组织与权限

### 3.1 用户管理

- 新增用户：账号、昵称、部门、角色、初始密码（留空自动生成强密码）。
- 列表支持搜索、启用/停用、重置密码、删除；重置后的密码只显示一次，请及时记录。
- 「更多」菜单里还可以重置密码、查看详情。

### 3.2 角色管理

- 角色绑定「菜单权限」：勾选哪些菜单与按钮，用户登录后就能看到/操作哪些。
- 数据权限：全部 / 本部门 / 本部门及以下 / 仅本人 / 自定义部门。
- 权限变更后，相关用户需要重新登录（或刷新页面）才生效。

### 3.3 菜单管理

- 目录、页面、按钮、接口四类节点；页面的「权限标识」同时是后端接口的校验码。
- 自定义菜单要填写「组件路径」（如 `system/user/index`，对应前端页面文件）。

### 3.4 部门与岗位

- 部门是树形结构，用户挂到部门上，数据权限依赖它。
- 岗位用于标识职责，可被用户引用。

## 4. 系统设置

### 4.1 站点设置（个性化配置）

保存后登录页与浏览器标题立即生效：

| 配置项 | 说明 |
| --- | --- |
| 网站名称 | 登录页标题、浏览器标签标题、顶栏品牌名 |
| 站点 logo | 建议 1:1 透明底 PNG/SVG，≤ 2MB |
| 登录页背景图 | 建议 1920×1080，≤ 2MB；留空用默认插画 |
| 登录页描述 / 副标题 | 登录页左侧大标题与下方说明，留空用默认文案 |
| 开放注册 | 关闭后登录页隐藏注册入口，注册路由不可达 |
| 图形验证码 | 关闭后登录不再要求输入图片验证码 |
| 滑块校验 | 关闭后无需拖动滑块，直接点「登录」 |

右侧提供效果预览；改完刷新登录页即可看到变化，无需重启服务。

> 验证码是防撞库的最后一道防线，只有在内网或已接单点登录时才建议关闭。

### 4.2 字典管理

- 左侧字典类型（如「用户性别」），右侧字典项（标签 / 键值 / 排序 / 标签样式 / 状态）。
- 下拉框、状态标签全站统一取字典，改字典即全站生效。

### 4.3 参数配置

键值型参数（上传大小限制、是否多租户等），部分参数以公开接口暴露给前端（如登录开关）。

### 4.4 租户管理

- 每个租户有独立的数据空间与默认部门；用户登录后自动带入所属租户。
- 列表查询自动按租户过滤，管理员不需要手动筛。

### 4.5 文件管理

- 上传：默认最大 20MB，白名单包含图片、PDF、Office、压缩包、txt、mp4。
- 存储：本地磁盘（`/static` 访问）或阿里云 OSS（可私有读 + 签名 URL）。
- 目录：文件按上传日期自动分目录（`年/月/日/业务/`），文件名带日期时间；
  列表上方可用「今天 / 近 7 天 / 本月」或自定义日期区间快速定位，「存储目录」列可直观看到位置。
- 上传方式（自动选择）：配置为 OSS 时浏览器直传（省带宽）；本地磁盘或直传失败时经服务端中转。
  OSS 直传需要运维在 Bucket 上配置 CORS。

### 4.6 定时任务

三种执行方式，调度策略（cron / 超时 / 重试 / 启停）通用：

| 类型 | 执行内容 | 适合做什么 |
| --- | --- | --- |
| 内置处理器 | 程序里已实现的维护动作（清会话、清日志…） | 系统自身定期维护 |
| HTTP 调用 | 你填的回调地址 + 方法 | 定时触发第三方系统 |
| Shell 脚本 | 在线填写的 sh/bash/python 脚本 | 自定义运维脚本、数据处理 |

- Shell 类型默认关闭：需要运维在配置里打开 `scheduler.shell_enabled`，否则新增时该类型置灰。
- 支持「立即执行一次」、启用/停用、查看执行日志（含脚本输出）。
- 多副本部署时通过租约保证同一时刻只有一台执行。

### 4.7 通知公告管理

- 起草 → 发布（发布时给本租户所有启用用户扇出站内信）→ 关闭。
- 已关闭的公告不能再修改，避免「发出去的公告被静默篡改」。
- 普通用户在「工作台 → 通知公告」页签里查看。

### 4.8 消息与待办（推送）

- **推送站内信**：选择接收人（不选=全员）、标题、内容、类型；可选「幂等键」，同键重复提交不会重复推送。
- **派发待办**：选择负责人、标题、优先级、截止时间、业务链接；同样支持幂等键。
- 页面也是业务系统对接的调试入口（外部系统调用 `POST /api/v1/open/messages`、`/open/todos`）。

### 4.9 代码生成

- 选择数据库表 → 预览生成的 Go 实体/服务/接口、Vue 页面、SQL 菜单脚本 → 打包下载。
- 生成结果按本脚手架的约定产出，复制进项目即可继续开发。

## 5. 系统监控

| 菜单 | 内容 |
| --- | --- |
| 在线用户 | 当前在线会话列表，可强制下线（踢出后该用户需重新登录） |
| 服务器信息 | CPU / 内存 / 磁盘 / 运行时环境 |
| 登录日志 | 登录成功失败记录、IP、时间、失败原因 |
| 操作日志 | 接口调用审计，支持字段级「修改前/修改后」对比 |

## 6. 界面与快捷键

- **搜索**：顶栏搜索框或 `Ctrl + K` 打开全局菜单搜索。
- **主题**：顶栏月亮/太阳图标切换明暗；右上角「设置」可调主题色、菜单布局、水印等。
- **表格设置**：列表右上角「设置」可切换斑马纹、边框、表头背景与表格密度，全局生效。
- **标签页**：打开的页面以页签形式保留，可右键关闭其它/全部。

## 7. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 登录提示验证码错误 | 验证码一次性使用，刷新页面重新获取；多次失败请稍后再试 |
| 登录提示账号锁定 | 连续失败触发锁定，等待锁定时间结束或联系管理员解锁 |
| 改密码提示「还需要包含大写字母」 | 密码规则未满足，按提示补齐即可（§1.2） |
| 保存后只弹一次提示 | 正常现象：成功提示统一由接口层给出 |
| 看不到某个菜单 | 角色未勾选该菜单权限；让管理员授权后重新登录 |
| 上传大文件很慢 | 让运维把存储切到 OSS 并配置 CORS，浏览器会直传 |
| 找不到以前上传的文件 | 文件按日期分目录存放，用列表上方的日期筛选或「存储目录」列定位 |
| 操作日志里看到两条相同记录 | 一条是业务操作、一条是后台任务触发，可按「操作人」区分 |
| 页面数据没更新 | 点右上角刷新按钮，或重新进入该页签 |
| 工作台卡片一直转圈 | 概览接口较慢（在线用户很多时更明显）。系统已改为批量查询，若仍长时间转圈请点「重新加载」并联系管理员查看服务状态 |
